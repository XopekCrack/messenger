# messenger

Локальный мессенджер для организации (self-hosted, Windows 7/10).

- [`mini-messenger/`](mini-messenger/README.md) — сервер (Node.js + Express + WebSocket + SQLite) и веб-панель администратора.
- [`desktop-client/`](desktop-client/README-desktop-client.md) — десктоп-клиент для сотрудников (Electron, .exe для Windows 7/8.1/10).
